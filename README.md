# 📊 LAMMPS Plotting Tool

A specialized, lightweight, extendable and easy-to-use Python toolkit explicitly designed for parsing and visualizing output files generated by **LAMMPS** (Large-scale Atomic/Molecular Massively Parallel Simulator). 

Whether you need to plot interatomic potentials, analyze structural properties, or chart general simulation data, this tool streamlines the process of turning raw LAMMPS text outputs into clean, readable graphs.

---

## ✨ Features

The tool provides modular, dedicated scripts to handle specific types of LAMMPS analysis outputs:

*   📈 **General Data Plotting (`plot.py`)**: A versatile script for plotting standard LAMMPS output data (e.g., thermodynamic outputs or custom fixes).
*   ⚛️ **Potentials (`plot_potential.py`)**: Visualize tabulated interatomic potentials and force fields.
*   ⭕ **Radial Distribution Function (`plot_rdf.py`)**: Easily plot radial distribution function data to analyze the local structure of your simulated materials.
*   🎇 **X-Ray Diffraction (`plot_xrd.py`)**: Generate and visualize XRD patterns directly from your LAMMPS compute outputs.
*   🛠️ **Command-Line Wrapper (`bin/myplots`)**: Includes a binary utility for quick terminal access.

---

## 💻 Prerequisites

This tool is built on standard scientific Python libraries. The required dependencies are listed in the `requirements.txt` file:

*   `numpy`
*   `matplotlib`

---

## 🚀 Installation & Usage

1. **Clone the repository:**
    
        git clone https://github.com/latusbombel/lammps-plotting-tool.git
        cd lammps-plotting-tool

2. **Install dependencies:**
   Install the required packages using the provided `requirements.txt`:
       
        pip install -r requirements.txt

3. **Run the scripts:**
   Use the individual Python scripts directly depending on the specific LAMMPS file you want to visualize.
       
        python plot_rdf.py <path_to_lammps_rdf_file>
        python plot_xrd.py <path_to_lammps_xrd_file>
